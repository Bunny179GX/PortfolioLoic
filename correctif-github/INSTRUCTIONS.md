# Correctif des images GitHub Pages

## Cause

Le site cherchait les médias dans `assets/images/...` et `assets/media/...`, alors que le dépôt GitHub les contient directement dans `photos/`, `creations/`, `communication/`, `logos/`, `moi/` et `videos/`.

## Fichiers à remplacer sur GitHub

Déposer les trois fichiers suivants à la racine du dépôt `PortfolioLoic` et accepter leur remplacement :

- `index.html`
- `gallery.js`
- `videos.html`

Il n’est pas nécessaire de renvoyer les images ou les vidéos : elles sont déjà présentes dans le dépôt.

Après le remplacement, attendre environ une à trois minutes puis recharger la page avec `Ctrl + F5`.
