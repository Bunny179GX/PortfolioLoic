# Mise à jour du portfolio sur GitHub

## Fichiers à remplacer

À la racine du dépôt GitHub `PortfolioLoic`, déposer les fichiers suivants depuis ce dossier et accepter leur remplacement :

- `index.html`
- `photos.html`
- `creations.html`
- `communication.html`
- `logos.html`
- `videos.html`
- `styles.css`
- `gallery.js`

Les versions ajoutées aux liens CSS et JavaScript forcent les navigateurs et les téléphones à charger la mise à jour au lieu d'afficher une ancienne copie en cache.

## Trois créations Peter Parker

Dans le dossier `creations` du dépôt GitHub, déposer également :

- `peter-pluie-intense.png`
- `peter-ciel-lumineux.png`
- `peter-version-sombre.png`

Ces trois images apparaissent côte à côte sur ordinateur dans une étude comparative accompagnée de courts textes. Sur téléphone, cette étude se parcourt horizontalement.

## Nouvelles interactions

Dans toutes les galeries d'images, un clic ouvre désormais une visionneuse permettant de passer à l'image précédente ou suivante :

- avec les flèches visibles à l'écran ;
- avec les touches fléchées du clavier sur ordinateur ;
- avec les flèches ou un glissement horizontal sur téléphone.

Le portrait d'accueil est aussi plus petit et mieux cadré sur ordinateur. Son format carré sur téléphone reste inchangé.

Après l'envoi, attendre une à trois minutes, ouvrir le site puis effectuer un rechargement forcé avec `Ctrl + F5` sur ordinateur. Sur téléphone, fermer puis rouvrir la page si l'ancienne version reste affichée.
