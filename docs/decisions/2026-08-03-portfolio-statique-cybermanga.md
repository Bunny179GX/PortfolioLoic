# Portfolio statique à direction cybermanga

Date : 2026-08-03

## Décision

Construire un site statique autonome dans `projet/`, avec une direction artistique sombre, jaune électrique, cyan et magenta. Les codes manga apparaissent dans la typographie expressive, les cadres, les numéros de chapitre et l’énergie des compositions. Les codes cyberpunk apparaissent dans la grille, les contrastes néon et les micro-détails techniques.

L’animation de livre est interprétée comme une transition légère en perspective lors de l’ouverture d’une page projet, complétée par des révélations rappelant une page qui se déploie.

## Raisons

- Publication simple et gratuite sur GitHub Pages.
- Aucun processus de compilation à expliquer ou maintenir.
- Univers original sans reprendre directement une licence ou un personnage existant dans l’interface.
- Animations assez légères pour préserver la lisibilité et les performances.
- Médias intégrés et consultables même avant l’ajout de services externes.

## Conséquences

- Le formulaire de contact n’est pas ajouté tant qu’aucune adresse courriel professionnelle n’est fournie.
- L’adresse postale privée n’est pas affichée publiquement.
- Les descriptions de galerie sont génériques lorsque le contexte précis d’une image n’est pas connu.
- Les vidéos publiées sont des versions optimisées ; les masters restent dans le dossier source.
