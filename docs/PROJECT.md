# Portfolio de Loïc Gex

## Objectif

Créer un portfolio public, professionnel et facile à transmettre par un simple lien. Le site présente Loïc Gex, ses compétences multimédias et ses réalisations par discipline.

## Demande confirmée au 2026-08-03

- Navigation principale : « Qui suis-je ? », « Projets », « Me contacter ».
- Grande bannière d’introduction.
- Bloc projets avec accès à une page dédiée par catégorie.
- Catégories actuelles : photographie, créations graphiques, vidéo/GIF, communication visuelle et logos.
- Direction visuelle : rencontre entre manga et cyberpunk futuriste, avec une présentation qui reste professionnelle.
- Animation souhaitée : sensation d’ouverture ou de page tournée, sans sacrifier les fonctions essentielles.
- Utiliser les images, vidéos et textes Word fournis dans les dossiers sources.
- Reformuler les textes lorsque cela améliore la clarté et le professionnalisme.
- Conserver les demandes et décisions utiles dans la documentation du projet.
- Préparer un dossier publiable sur GitHub Pages.

## Contenu éditorial

Le texte de présentation a été reformulé à partir du document Word fourni. Il conserve les faits suivants :

- Loïc Gex, né le 18 février 2003 et âgé de 23 ans au 2026-08-03 ;
- titulaire d’un CFC de médiamaticien obtenu après quatre années d’apprentissage ;
- pratique du graphisme, de la vidéo, de la photo et du web ;
- maîtrise annoncée de Photoshop, Premiere Pro et Illustrator ;
- parcours incluant le football semi-professionnel à Barcelone, la vente, la garderie, l’agriculture et les Samaritains ;
- intérêt pour les univers futuristes et le cyberdesign ;
- passion pour le manga, les jeux vidéo et le sport ;
- réalisations produites pendant l’apprentissage ou auparavant, lors d’un préapprentissage.

La page publique indique seulement « Orbe, Suisse », le téléphone fourni et l’adresse `lgex@icloud.com`. L’adresse postale privée complète n’est pas publiée.

## État actuel

Deux variantes fonctionnelles sont disponibles :

- `projet/` : version cyberpunk professionnelle ;
- `projet manga/` : version manga/anime d’aventure, principalement inspirée par l’énergie de One Piece.

La variante manga reprend les mêmes informations, coordonnées, projets et médias afin de permettre une comparaison directe. Les améliorations futures pourront porter sur les titres et descriptions détaillés de chaque image, les liens sociaux, un CV téléchargeable et le choix d’une sélection plus courte de projets phares.
