# Portfolio de Loïc Gex

Site statique prêt à publier sur GitHub Pages.

## Voir le site sur ce PC

Ouvrir `index.html` dans un navigateur. Toutes les pages, images et vidéos nécessaires sont incluses dans ce dossier.

## Publier sur GitHub Pages

1. Créer un nouveau dépôt GitHub, par exemple `portfolio-loic-gex`.
2. Déposer **le contenu du dossier `projet`** à la racine du dépôt. `index.html` doit être directement visible à la racine.
3. Ouvrir les paramètres du dépôt : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main`, le dossier `/ (root)`, puis enregistrer.
6. Attendre la publication. GitHub affichera l’adresse publique du site.

Ne pas déposer le dossier source `image` sur GitHub : il contient les masters vidéo de plus de 100 Mo. Les versions adaptées au web sont déjà présentes dans `projet/assets/media/videos`.

## Modifier le contenu

- Présentation et accueil : `index.html`.
- Couleurs et mise en page : `styles.css`.
- Liste des images : `gallery.js`.
- Médias du site : `assets/`.
