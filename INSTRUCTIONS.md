# Mise à jour chronologique du portfolio

Cette livraison ajoute la biographie complète, la création Chishiya et le classement chronologique ou thématique de toutes les galeries.

## 1. Remplacer le code à la racine

Ouvrir directement : <https://github.com/Bunny179GX/PortfolioLoic/upload/main>

Sans ouvrir aucun sous-dossier, déposer ces huit fichiers et accepter leur remplacement :

- `index.html`
- `photos.html`
- `creations.html`
- `communication.html`
- `logos.html`
- `videos.html`
- `styles.css`
- `gallery.js`

Le bon écran GitHub affiche notamment `README.md`, `index.html`, `styles.css`, ainsi que les dossiers `photos`, `communication`, `logos` et `videos`.

## 2. Restaurer le dossier creations

Le dossier `/creations` a disparu du dépôt GitHub lors de la précédente manipulation. Depuis l'écran d'envoi à la racine, glisser le dossier complet `creations` présent dans ce dossier de livraison.

Avant de valider, GitHub doit afficher des chemins tels que :

- `creations/ammo1.png`
- `creations/chishiya-carte.png`
- `creations/peter-pluie-intense.png`
- `creations/sansfaucheur.jpg`

Le dossier contient les 18 créations nécessaires au site. Ne pas déposer les images seules à la racine.

## 3. Publier

Cliquer une seule fois sur **Commit changes**, puis attendre que le nouveau déploiement devienne vert dans <https://github.com/Bunny179GX/PortfolioLoic/actions>.

Quand le déploiement est terminé, ouvrir <https://bunny179gx.github.io/PortfolioLoic/> et effectuer `Ctrl + F5`.
